プライバシーポリシー

最終更新日：2026年6月6日
luluju（以下「本アプリ」）は、ユーザーのプライバシーを最優先事項として設計されています。本ポリシーは、本アプリが収集する情報、その使用方法、およびユーザーの権利について説明します。

1. 収集する情報

本アプリは以下の情報を収集する場合があります：

  • アカウント情報：メールアドレス、表示名（Google/Apple アカウント経由）
  • メール情報：連携した Gmail・Outlook のメール件名、差出人、本文（要約処理のため）
  • カレンダー情報：Google カレンダー・Apple カレンダーの予定タイトル、日時、場所
  • メッセージ情報：Slack・Microsoft Teams・LINE の受信メッセージ（要約処理のため）
  • 位置情報：天気情報取得のための現在地（設定でON/OFFが可能）
  • 利用設定：アプリ内で設定したユーザー名、好みの情報、通知設定

2. 情報の使用目的

収集した情報は以下の目的にのみ使用します：

  • AIによるメール返信案・スケジュール提案の生成
  • 毎日のブリーフ（要約）の生成
  • 天気情報・周辺場所の取得
  • アプリ内チャット機能での応答生成
  • ユーザー設定の保存と同期

収集した情報を、広告目的で第三者に販売・提供することは一切ありません。

3. 情報の共有

以下の第三者サービスにデータを送信する場合があります：

  • OpenAI：AI返信生成・要約処理のため（OpenAI プライバシーポリシー）
  • Supabase：データベース・認証基盤として使用（Supabase プライバシーポリシー）
  • Google：Gmail・カレンダー・Maps API として使用（Google プライバシーポリシー）
  • Microsoft：Teams・Outlook API として使用（Microsoft プライバシーポリシー）
  • OpenWeatherMap：天気情報取得のため使用

4. データの保存期間

  • チャット履歴：直近30日間（設定で学習をOFFにすると保存されません）
  • OAuth アクセストークン：連携解除まで暗号化して保存
  • アプリ設定：アカウント削除まで保存
  • 処理済みメール・メッセージ本文：サーバーには保存しません（処理後即時破棄）

5. データのセキュリティ

すべての通信は TLS/HTTPS で暗号化されます。アクセストークンは暗号化した上でデータベースに保存し、第三者がアクセスできない構成を採用しています。

6. ユーザーの権利

ユーザーはいつでも以下の権利を行使できます：

  • 保存データの確認・修正・削除の請求
  • 各連携アプリのアクセス権限の取り消し
  • アカウントの完全削除（設定画面から実行可能）
  • AI学習・パターン収集のOFF（設定画面から変更可能）

7. 子どもの利用

本アプリは13歳未満の方を対象としていません。13歳未満の方の個人情報を故意に収集することはありません。

8. 本ポリシーの変更

本ポリシーを変更する場合、アプリ内の通知または本ページでお知らせします。重大な変更がある場合は、メールでもご連絡します。
